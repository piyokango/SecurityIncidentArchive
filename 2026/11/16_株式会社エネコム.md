# 本文
当社は、2026年10月9日に公表いたしました当社社内ネットワークへの不正アクセス事案（以下「本事案」）について、調査を完了し、その結果を踏まえた対策を実施いたしましたのでお知らせいたします。

これまで当社において外部専門機関と連携しつつ実施してきた一連の調査および必要な対策については、今般、外部専門機関による評価においても重大な未解決事項がないことが確認できました。

当社としては、これらを踏まえ、本事案において確認された侵入経路に対する必要な遮断措置は完了し、現在は安全な事業運営を継続できる状態となったものと判断しております。

なお、調査の結果、流出した可能性のある情報が不特定多数に公開された事実や不正利用された事実は、現時点で確認されておらず、光インターネットサービス「メガ・エッグ」に関わるお客さま情報の流出も確認されておりません。

本事案により影響を受けた可能性のあるお客さまや関係者の皆さまへは、個別対応を行うとともに、今後も継続的な監視とセキュリティ対策の強化を含む再発防止策に取り組んでまいります。

お客さまをはじめ関係者の皆さまに、多大なるご心配とご迷惑をお掛けしておりますことを、改めて深くお詫び申し上げます。

本事案に関する概要および対策は、以下のとおりです。

## 1．本事案の概要

2026年10月6日（火）、第三者による外部から当社社内ネットワークへの不正アクセスを確認いたしました。

当社は、異常を確認したのち、速やかに外部接続を遮断し、被害拡大を防止するための緊急対応を実施するとともに、外部専門機関と連携し、フォレンジック調査を含む侵入経路、原因および影響範囲の調査を進めました。

調査により確認した本事案の概要は、次のとおりです。

| 項目 | 内容 |
|---|---|
| 不正アクセスの確認 | 2026年10月6日（火） |
| 不正アクセス箇所 | シンクライアント環境（以下「シンクラ環境」） |
| 不正アクセス方法 | ・不正取得した保守用アカウントの情報を利用して、シンクラ環境を経由して社内ネットワークに侵入し、さらに当社の複数社員の正規アカウント情報を不正取得。<br>・不正取得した保守用、当社社員の正規アカウントを利用し、シンクラ環境を経由して社内ネットワークに侵入。<br>※事業用ネットワークについては、不正アクセスは確認されておりません。 |
| 不正アクセスにより流出したことが確認された情報および流出した可能性のある情報 | ・社内ファイルサーバーに保存してある業務資料、報告書、議事録の一部など。<br>・対象のお客さまについては、当社から連絡がつかない方を除き個別にお知らせしております。<br>・流出した個人情報※は、2,940件（うち当社社員情報1,838件）<br><br>※お客さまおよび当社の社員等に関する、氏名、勤務先・所属、役職、電子メールアドレス、電話番号等（銀行口座情報およびクレジットカード情報は含まれておりません）。<br>なお、光インターネットサービス「メガ・エッグ」および法人回線サービスに係るお客さまの個人情報の流出は確認されておりません。 |
| 調査・評価方法 | 社内の専門部署および外部専門機関と連携し、フォレンジック調査も含めた侵入経路、原因および影響範囲の調査 |

## 2．本事案発覚後の対応

当社は、本事案の発覚後、緊急対策本部を立ち上げ、被害拡大を防止する緊急対応を実施するとともに、調査の過程で判明した状況を踏まえ、次の対策を実施いたしました。

| 項目 | 内容 |
|---|---|
| 侵入経路の遮断 | ・社外からシンクラ環境への接続を遮断（前回ニュースリリースにて報告済み） |
| ログ調査 | ・侵入経路、流出情報の確認<br>・不正アクセスを受けた機器等の特定 |
| アカウント管理 | ・不正取得された保守用アカウントの削除および全社員のパスワードの変更<br>・アカウント管理・運用の見直し |
| 健全性確認 | ・ネットワーク機器の健全性確認<br>・当社サーバーの健全性確認 |
| 認証・接続制限 | ・2026年10月13日に全社ゼロトラスト環境※へ移行<br><br>※端末認証、生体認証を含む認証方式の強化など |
| 継続監視 | ・新たな不正アクセスに対する継続監視 |

なお、外部専門機関からは、当社の調査範囲および調査により確認された侵入経路に対する必要な遮断措置の実施について、いずれも妥当であるとの評価を受けております。

引き続き、不正アクセスに対する監視の継続、アクセス制限の強化を実施するとともに、情報セキュリティ体制の見直しを進めてまいります。

## 3．お客さまおよび関係者の皆さまへの対応

本事案により影響を受けた可能性のあるお客さまに対し、ご説明をしております。

また、関係行政機関への報告を行うとともに、関係先との連携を進めております。
