# 公表概要

- 2026年11月11日
- 株式会社山善
- https://www.yamazen.co.jp/news/entry-2949.html

# 事案ID
- 2026-11-11-株式会社山善

# 公表種別
- 初報

# 本文
株式会社山善のコーポレートサイトが利用する外部サーバーに不審なファイルを発見しました。現在、ファイルの除去作業および情報漏洩等の可能性を含めて調査を進めるとともに、お客様の安全確保のため、当社コーポレートや関連サイト（山善 BASE CAMP、BCP.ERS）を一時停止しております。

なお、現時点の調査では、情報の漏洩は確認されておりませんが、引き続き調査を進めております。

お客様には多大なるご不便とご心配をおかけしておりますことを、深くお詫び申し上げます。

調査状況および今後の対応につきましては、詳細が判明し次第、当コーポレートサイトにて改めてご案内いたします。

関係する皆様におかれましては、不審なメールや通知が届いた場合は、開封やリンク先へのアクセスを行わず、十分ご注意いただきますようお願い申し上げます。
