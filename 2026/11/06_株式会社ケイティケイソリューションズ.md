# 本文
株式会社ケイティケイソリューションズ（以下「当社」）が管理・運営するシステムにおきまして、外部からの第三者による不正アクセスが発生し、一部のサービスにおいて個人情報を含むデータが不正に取得・送信されたことが判明いたしました。

日頃より当社サービスをご利用いただいているお客様、お取引先様、ならびに関係医療機関・利用者の皆様に、多大なるご迷惑とご心配をおかけしておりますことを、深くお詫び申し上げます。

現在、当社では外部のセキュリティ専門事業者と連携し、被害状況の全容解明および安全性の確認に向けた調査を緊急で実施しております。現時点で判明している事実関係および当社の対応状況につきまして、以下の通りご報告申し上げます。

## 1. 本件の概要および発生経緯

2026年10月14日、当社のサーバー環境に対する第三者からの不正アクセスを検知いたしました。検知後直ちに、攻撃元からの通信遮断および該当サーバーの停止措置を講じ、被害拡大の防止に努めております。

監視システムおよびログの解析におきまして、2026年10月22日以降、攻撃者による新たな活動は確認されておりません。また、2026年10月26日より外部の専門事業者による調査を開始し、侵入経路の特定および影響範囲の解析を進めております。

| 項目 | 日時 | 内容 |
|---|---|---|
| 不正アクセスの検知 | 2026年10月14日 | 当社サーバーに対する第三者による不正アクセスを検知 |
| 応急対応（被害拡大防止） |  | 直ちに攻撃元IPアドレスからの通信遮断および該当サーバーの停止措置を実施 |
| 攻撃活動の状況 | 2026年10月22日以降 | 現時点では、攻撃者による活動・不正アクセスは検知されておりません |
| 調査開始 | 2026年10月26日 | 外部の専門事業者による本格的な詳細調査を開始 |

## 2. 調査で判明した事項（サービスごとの影響・調査状況）

本報告にあたりましては、調査により事実が確認された事項と現在も調査が継続している事項を明確に分離し、誠実かつ正確な開示を行っております。

一部のメールサービス等につきましてはデータの不正取得および外部送信が【確認済み】となっております。また、医療機関向け診療予約システム等につきましては、現時点で一括取得の記録は確認されておりませんが、可能性を否定できないため【調査中】として継続対応を行っております。

## 3. これまでに実施した対応および再発防止策

当社では、事象の検知以降、以下の対応を迅速に進めております。

### アクセス遮断・被害拡大防止

不正アクセス検知後、直ちに該当サーバーの隔離および外部からの攻撃通信遮断措置を完了いたしました。

### アカウントのパスワード再設定

影響を受けた可能性のあるアカウントにつきましては、当社にて即時にパスワードの初期化・再設定措置を実施いたしました。

### 関係当局への報告

本件につきましては、個人情報保護委員会および関係当局へ速やかに報告を行っております。

### 再発防止体制の構築

外部専門事業者の知見を取り入れ、脆弱性の修正、不正プログラムの検知・監視体制の強化を緊急で進めております。

## 4. お客様へのお願い（二次被害防止に関するご注意）

対象サービスをご利用のお客様および関係者の皆様におかれましては、二次被害を防止するため、以下の点にご注意いただけますようお願い申し上げます。

### 不審メールへの警戒

取得されたメール情報を悪用し、当社やお取引先様、公的機関等を装った不審なメール（フィッシングメール等）が送信されるおそれがあります。心当たりのないメールの添付ファイルや本文中のリンク・URLは開かないようご注意ください。

### パスワード詐取へのご注意

当社から、メールや電話でお客様のパスワードをお尋ねすることは一切ございません。当社を装う不審な連絡には応じないようご注意ください。

## 5. 今後の見通し

現在も外部専門事業者の協力のもと、システム全般にわたる詳細な調査を継続しております。今後、調査により新たな事実や詳細な影響範囲が判明した場合には、速やかに本ウェブサイトにてお知らせいたします。
