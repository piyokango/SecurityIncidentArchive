# 本文
本日、本学の情報基盤システムにおいて大規模な障害が発生いたしました。

ご利用の皆様、関係者の皆様に多大なご迷惑とご心配をおかけしておりますことを、深くお詫び申し上げます。現在、原因の調査および復旧作業を行っておりますが、現時点で判明している概要について、第二報を下記のとおりお知らせいたします。

記

## 1. 授業(講義)の対応について

システム障害に伴い、10月8日(木)までの授業は休講とします。

10月9日(金) 以降に対面授業を再開する予定です。オンライン授業の再開時期については今後の復旧状況を踏まえ判断します。

## 2. 授業・入試など最新の情報発信について

授業に関する今後の連絡および入試関連の最新情報は、すべて下記のOMU エントランスページにて随時更新・発信しております。

入試に関する WEB 出願サイト・入学手続サイトにつきましては、学外の外部サーバーにて運用を行っているため、登録はできる状況です。

WEB 出願サイト・入学手続サイトへのアクセスリンクについても、OMUエントランスページ内に掲載しております。

ただし、出願において、募集要項の閲覧や一部の出願書類が入手できなくなっておりまずが、希望者全員が出願できるよう対応を検討しております。
