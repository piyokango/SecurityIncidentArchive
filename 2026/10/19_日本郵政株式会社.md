# 本文
日本郵政株式会社（東京都千代田区、取締役兼代表執行役社長 根岸 一行）が提供しております「ゆう ID」について、第三者による不正利用および会員情報漏えいの可能性が判明しましたので、お知らせします。調査の結果、本件は外部で漏えいした ID・パスワードのリストを用いて、ゆう ID 会員になりすました不正ログインが判明しております。お客さまには、多大なるご迷惑とご心配をおかけしておりますことを深くお詫び申し上げます。本件の影響範囲および再発防止に向けた対応について、以下のとおりお知らせします。

## 1 経緯
2026 年 10 月 15 日(木)、当社が提供する「ゆうゆうポイント」公式サイト（以下「ゆうゆうポイントサイト」という。）において、不審なアクセスを検知しました。

その後の調査の結果、第三者が一部のゆう ID アカウントになりすまし、ゆうゆうポイントサイトにログインし利用していたことが判明しました。

これを受け、お客さま保護を最優先に対応するため、10 月 16 日(金)よりゆうゆうポイントサイトを停止しております。

## 2 不正ログインの状況および会員情報漏えいの可能性について
調査の結果、不正にログインされた可能性のあるアカウントは、249 件であることを確認しました。

また、第三者が外部で不正に取得した ID・パスワードを利用してゆうゆうポイントサイトに不正にログインし、以下のゆう ID 会員情報が閲覧された可能性があります。

該当するお客さまへは、電話等により順次ご連絡しています。なお、2026 年 9 月 29 日(火)に公表しました郵便局アプリへの不正アクセスにより取得されたゆう ID とは重複しておらず、現時点において、当社システムからの情報漏えいは確認されておりません。

## 3 ゆう ID をご利用のお客さまへのお願い

ゆう ID をご利用の皆さまのアカウント保護のため、以下の対応をご検討くださいますようお願いいたします。

### (1) パスワード変更等
当社から、ログイン時に必要となるパスワードや登録メールアドレスの再設定、パスキー設定のお願いおよび二段階認証の必須化に関するご案内を順次お送りいたします。

メールの内容をご確認いただき、速やかにパスワードの再設定等をお願いいたします。

また、他のサービスと同一のパスワードを設定されている場合は、異なるパスワードへの変更をご検討ください。

なお、アクセス集中によりサイトにつながりにくい場合は、お手数ですが時間をおいて再度ご利用ください。

### (2) 不審なメールや連絡への注意
当社やグループ各社等を装い、偽サイトへ誘導して個人情報等を入力させようとする不審なメールや SMS 等が送信される可能性があります。

当社およびグループ会社が、電話やメール等でパスワードやクレジットカード番号をお尋ねすることはありません。

身に覚えのないメールや SMS に記載された URL や添付ファイルは開かず、不審な Web サイトに個人情報やパスワード等を入力しないよう十分ご注意ください。

## 4 今後について
当社では、当該不審 IP アドレスからのアクセスを速やかに遮断するとともに、現在も継続して監視を行っております。なお、対応完了後、新たな不正アクセスは確認されていません。

今後、新たに公表すべき事実が判明した場合には、当社 Web サイト等を通じて速やかにお知らせします。

また、ゆう ID およびゆうゆうポイントをご利用いただくお客さまの情報をより適切に保護するため、引き続きセキュリティ対策の強化に取り組んでまいります。

該当のお客さまおよび今回の緊急メンテナンス中にゆうゆうポイントのご利用を予定されていたお客さまに、多大なるご迷惑とご心配をおかけしましたことを、深くお詫び申し上げます。

当社では今回の事態を真摯に受け止め、再発防止およびセキュリティ強化に全力で取り組んでまいります。
