# 本文
2026年10月2日未明より、本学の情報基盤システムにおいて発生した大規模障害について、ご利用の皆様、関係者の皆様に多大なご迷惑とご心配をおかけしておりますことを、深くお詫び申し上げます。引き続き原因の調査および復旧作業は継続中ですが、当初のご案内通り10月9日（金）から、すべてのキャンパスでの対面授業を再開します。

## 1. 授業開始日

2026年10月9日（金）

## 2. 臨時で利用可能な機能と、留意事項

授業再開に必要な環境を確保するため、臨時に授業支援システムを始めとする各種システムを構築しました。現時点で利用可能となった機能・項目は以下のとおりです。

| 機能・システム名 | 内容 |
| --- | --- |
| 臨時Moodle（学習管理システム） | 授業の資料・時間割・教室情報、教員からの連絡、学生の課題提出・教員への問い合わせなど、教員と学生の双方向のやりとりが可能 |
| 臨時学生Navi（ポータルサイト） | 学生生活、授業に関する情報（履修手続等）のお知らせ |
| 学務情報システム | 授業科目の検索や成績の閲覧等 |
| 臨時授業カタログ | シラバス（授業計画）や教科書情報の確認 |
| 臨時デジタル窓口 | 学生から大学職員への問い合わせや相談を受け付け |
| QR出席登録 | 大学アプリによるQRコードを用いた出席登録機能 |
