# 本文
このたび、当社が提供する採用管理プラットフォーム「Interview Cloud」「ApplyNow」「ApplyNow Sign」におきまして、当社で利用しているデータ分析ツールの脆弱性を突いた第三者による不正アクセスが発生し、当社のお客様および応募者様の個人データが外部へ漏えいした可能性が検知されました（以下「本件」といいます）。

なお、現時点において、お客様の情報が不正に利用された等の二次被害の発生は確認されておりません。

お客様ならびに関係者の皆様には、多大なるご迷惑とご心配をおかけする事態となりましたことを、心より深くお詫び申し上げます。

本件の概要と現在の状況、および今後の対応につきまして、下記のとおりお知らせいたします。

記

## 1. 本件の概要

当社システムにおいて利用しているデータ分析ツールの脆弱性を悪用した不正アクセスを受け、データベース内に保存されていた一部データに対し、第三者による不正アクセスが行われた痕跡が確認されました。 なお、画像・PDF等のファイル実体および面接動画データにつきましては別の保管領域にあるため、本件の不正アクセス対象外であることを確認しております。

## 2. 漏えいした可能性のある個人データについて

詳細は現在調査中ですが、2026年9月9日現在、判明している状況は以下のとおりです。

対象データ件数： 現在調査中

サービス名：面接シェアリングサービス『Interview Cloud』

項目： 氏名（カナ）、メールアドレス、電話番号を含む応募者情報、企業担当者のユーザー名、メールアドレス、権限、外部連携情報を含む企業ユーザー情報

サービス名：録画面接 『ApplyNow』

項目： 氏名（カナ）、メールアドレス、電話番号を含む応募者情報、企業担当者のユーザー名、メールアドレス、権限を含む企業ユーザー情報

サービス名：電子雇用契約 『ApplyNow Sign』

項目： 雇用契約情報、個人番号、基礎年金番号、金融機関口座情報を含む契約者情報、企業担当者のユーザー名、メールアドレス、権限を含む企業ユーザー情報

※個人番号が含まれる対象者様、および金融機関口座情報が含まれる対象者様におかれましては、個別の注意喚起およびサポート案内を順次差し上げてまいります。

## 3. 期間

不正アクセスが確認された期間： 2026年8月9日 〜 2026年9月7日

## 4. 経緯

2026年9月7日： 当社システム内部において異常なアクセスログを検知・調査したところ、不正アクセスの痕跡を確認いたしました。同日直ちに不正アクセスの遮断等の緊急措置を実施いたしました。

2026年9月7日以降： 弁護士と連携し、被害状況の全容解明および法的対応手続きを開始いたしました。また、影響を受ける可能性のある企業ユーザー様に対し、パスワード変更を促す緊急連絡を配信いたしました。
